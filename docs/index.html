Adaptive Trees on a GPU

Adaptive Trees on a GPU: Efficient GPU-aware Adaptive Tree Construction for the Fast Multipole Method

Nils Rottstegge1,2
1Department of Computer Science, ETH Zürich · 2Jülich Supercomputing Centre (JSC), Forschungszentrum Jülich, Guest Student Programme 2026 (August – October 2026)

This site collects the results of my project in the JSC Guest Student Programme 2026: a GPU implementation of adaptive octrees and binary trees for the Fast Multipole Method, built on the Cornerstone representation. The report describes the methods, the GPU optimisations and the benchmark results in detail, and the slides summarise the project as presented at JSC.

Report report/ Interactive article. Background, the adaptive tree update and the NFCount criterion, the TreeView construction, all GPU optimisations, the binary tree and the results, with interactive figures, dataset animations and a 3D tree viewer. Slides slides/ Presentation. The talk given at the end of the programme, with dataset animations, benchmark plots and the interactive viewer. Use the arrow keys to navigate.
